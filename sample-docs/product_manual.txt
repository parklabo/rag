스마트워치 X100 사용 설명서

제품 개요
스마트워치 X100은 최신 기술이 집약된 웨어러블 디바이스입니다.
건강 관리, 운동 추적, 알림 기능 등을 제공합니다.

주요 사양
- 디스플레이: 1.4인치 AMOLED, 454 x 454 해상도
- 프로세서: Snapdragon Wear 4100+
- 메모리: RAM 1GB, 저장공간 8GB
- 배터리: 450mAh (일반 사용 시 2일, 절전 모드 5일)
- 방수: IP68 등급 (수심 50m)
- 무게: 47g (스트랩 제외)
- 연결: Bluetooth 5.0, Wi-Fi, NFC

기본 설정

1. 충전하기
- 처음 사용 전 완전히 충전하세요 (약 2시간 소요)
- 자석식 충전 케이블을 시계 뒷면에 부착
- 충전 중 화면에 배터리 표시

2. 전원 켜기
- 오른쪽 상단 버튼 3초 이상 길게 누르기
- 로고가 나타나면 손을 뗍니다

3. 스마트폰 연결
- 스마트폰에서 'SmartWatch Connect' 앱 다운로드
- 앱 실행 후 블루투스 활성화
- '새 기기 추가' 선택
- 시계 화면에 표시된 페어링 코드 확인

주요 기능

건강 모니터링
- 심박수: 24시간 자동 측정
- 혈중 산소: 수동 측정 또는 수면 중 자동 측정
- 스트레스: 심박수 변이도 기반 측정
- 수면 추적: 얕은 수면, 깊은 수면, REM 수면 분석

운동 추적
- 100가지 이상의 운동 모드 지원
- GPS 내장으로 야외 활동 거리 및 경로 추적
- 자동 운동 감지 (걷기, 달리기, 자전거)
- 운동 후 상세 분석 리포트 제공

알림 기능
- 전화, 문자, 앱 알림 수신
- 알림 진동 강도 조절 가능
- 간단한 메시지 회신 가능 (미리 설정된 답장)

기타 기능
- 음악 재생 제어
- 날씨 정보
- 알람 및 타이머
- 스톱워치
- 나침반
- 손전등
- 결제 기능 (NFC)

버튼 및 제스처

하드웨어 버튼
- 상단 버튼: 전원/홈 (1회 클릭), 최근 앱 (2회 클릭)
- 하단 버튼: 운동 시작/정지 (커스터마이징 가능)

터치 제스처
- 위/아래 스와이프: 알림 및 메뉴 탐색
- 좌/우 스와이프: 위젯 화면 전환
- 화면 오래 누르기: 워치페이스 변경

배터리 관리

배터리 절약 팁
- 화면 밝기 자동 조절 사용
- 상시 표시 기능 끄기
- 사용하지 않는 센서 비활성화
- 알림 앱 선택적 허용

절전 모드
- 설정 > 배터리 > 절전 모드
- 활성화 시 기본 기능만 작동
- 시간 표시, 걸음 수, 심박수 측정만 가능

문제 해결

시계가 켜지지 않을 때
- 충전 케이블에 연결하여 30분 충전
- 전원 버튼 10초 이상 길게 눌러 강제 재시작

스마트폰 연결이 안 될 때
- 블루투스가 켜져 있는지 확인
- 시계와 폰을 재시작
- 앱에서 기기 삭제 후 다시 페어링
- 거리가 10m 이내인지 확인

터치가 작동하지 않을 때
- 화면 보호 필름 확인
- 손과 화면이 건조한지 확인
- 시계 재시작

충전이 느릴 때
- 순정 충전 케이블 사용 확인
- 충전 단자 청소 (마른 천 사용)
- 고속 충전 어댑터 사용 (5V/2A 권장)

- 물리적 충격, 침수 (방수 등급 초과)
